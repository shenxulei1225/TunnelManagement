# 🧩 **通用组件与模板系统说明文档**

## 📖 **概述**

隧道管理UI系统的通用组件与模板系统是一套完整的可复用UI解决方案，通过高度配置化的组件和模板化的页面设计，实现快速开发和统一的用户体验。系统采用"关注点分离"的设计原则，构建了多层次的模板架构。

## 🏗️ **系统架构**

### **多层模板概念**

系统采用四层模板架构设计：

1. **UI模板层** - TemplateGenerator.ts
   - 负责生成UI组件树
   - 处理组件的渲染逻辑
   - 管理组件间的数据流

2. **业务模板层** - TemplateRegistry.ts
   - 页面级模板管理
   - 业务场景的抽象和封装
   - 模板的注册和动态加载

3. **配置模板层** - TemplateConfigEngine.ts
   - 模板配置引擎
   - 配置项的验证和处理
   - 动态配置生成

4. **字段映射层** - TemplateFieldMapping.ts
   - 业务字段到UI组件的映射
   - 数据类型转换和适配
   - 字段级权限控制

### **系统分层架构**

#### **第1层：Template层 (模板定义和配置)**
- **职责**：What to render (渲染什么)
- **功能**：模板定义、UI结构、字段映射、配置生成
- **组件**：模板组件库、配置生成器、字段映射器

#### **第2层：API Adapter层 (数据适配)**
- **职责**：How to fetch (如何获取数据)
- **功能**：统一API接口、数据转换、请求封装
- **组件**：API适配器、数据转换器、请求管理器

#### **第3层：Business Logic层 (业务逻辑)**
- **职责**：What rules to apply (应用什么规则)
- **功能**：业务规则、权限控制、状态管理
- **组件**：业务规则引擎、权限管理器、状态管理器

#### **第4层：Data Access层 (数据访问)**
- **职责**：Where to get data (从哪里获取数据)
- **功能**：静态API、动态API、混合API
- **组件**：数据访问层、缓存管理、数据源管理

## 🚀 **使用指南**

### **快速开始**

#### **使用SuperTree组件**
```typescript
import { SuperTree, DEFAULT_CONFIG, FILE_MANAGER_PRESET } from '@/components/SuperTree'

// 使用默认配置
const config = DEFAULT_CONFIG

// 或使用预设
const fileManagerConfig = FILE_MANAGER_PRESET
```

#### **使用StandardDataView模板**
```vue
<template>
  <StandardDataView :config="dataViewConfig" />
</template>

<script setup>
import { StandardDataView } from '@/views/template'

const dataViewConfig = {
  title: '数据管理',
  treeConfig: { /* 树配置 */ },
  listConfig: { /* 列表配置 */ },
  formConfig: { /* 表单配置 */ }
}
</script>
```

#### **注册自定义模板**
```typescript
import { templateRegistry } from '@/views/dynamic/recommendation/templates/TemplateRegistry'

templateRegistry.registerCustomTemplate({
  id: 'my-custom-template',
  name: '我的自定义模板',
  description: '自定义模板描述',
  category: 'custom',
  component: defineAsyncComponent(() => import('./MyTemplate.vue'))
})
```
