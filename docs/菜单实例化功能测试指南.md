```sql
SELECT 
  name, 
  path,
  JSON_EXTRACT(dynamic_config, '$.parameterName') as parameter_name,
  JSON_EXTRACT(dynamic_config, '$.titleTemplate') as title_template,
  JSON_EXTRACT(dynamic_config, '$.enableMultiInstance') as multi_instance
FROM system_menu 
WHERE dynamic_config IS NOT NULL;
```

## 🐛 常见问题排查

### 问题1：动态路由不生效
**症状：** 访问动态路由时显示404或跳转错误

**检查：**
```javascript
// 检查路由是否正确注册
console.log(router.hasRoute('DragDropClassificationDynamic'))

// 检查路由配置
const route = router.resolve('/examples/drag-drop-classification/test')
console.log('路由解析结果:', route)
```

**解决：** 确认路由组件存在，路径配置正确

### 问题2：TagsView标题不更新
**症状：** 多个实例显示相同标题

**检查：**
```javascript
// 检查路由元数据
const currentRoute = useRoute()
console.log('当前路由meta:', currentRoute.meta)
console.log('当前路由params:', currentRoute.params)
```

**解决：** 确认 `titleTemplate` 和 `paramName` 配置正确

### 问题3：多实例缓存冲突
**症状：** 不同实例显示相同内容

**检查：**
```javascript
// 检查组件缓存键
import { useTagsViewStore } from '@/store/modules/tagsView'
const tagsViewStore = useTagsViewStore()

console.log('缓存的组件:', tagsViewStore.cachedViews)
```

**解决：** 确认 `cacheStrategy` 设置为 `'param-based'`
