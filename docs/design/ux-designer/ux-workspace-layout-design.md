# UX工作台布局设计方案

## 📋 设计理念

参考Figma、墨刀、蓝湖等主流设计工具的界面布局，降低用户学习成本，提供熟悉的操作体验。

## 🎯 整体布局结构

```
┌─────────────────────────────────────────────────────────────────┐
│                       顶部菜单栏                                  │
│ 品牌标识    │    设备预览切换    │    预览/导出                     │
├─────────────────────────────────────────────────────────────────┤
│       │                                    │                    │
│  左侧  │                                    │                    │
│  面板  │              画布区域                │      右侧面板        │
│       │                                    │                    │
│ ┌───┐ │                                    │                    │
│ │文件│ │                                    │                    │
│ │资产│ │                                    │                    │
│ │组件│ │                                    │                    │
│ └───┘ │                                    │                    │
│ ┌───┐ │                                    │                    │
│ │图层│ │                                    │                    │
│ │树  │ │                                    │                    │
│ └───┘ │                                    │                    │
└─────────────────────────────────────────────────────────────────┘
```

## 🔧 详细布局说明

### 1. 顶部菜单栏 (50px)
```scss
.top-menubar {
  height: 50px;
  background: #2c3e50; // 深色主题
  color: white;
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

**左侧：品牌标识**
- Universal X Designer - UX设计器

**中间：设备预览切换**
- 桌面 (🖥️) / 平板 (📱) / 手机 (📱)
- 响应式设计预览

**右侧：操作按钮**
- 预览 (👁️)
- 生成代码 (🚀)

### 2. 左侧面板 (280px)

#### 上半部分：资产和控件库
采用标签页结构，包含：

**📁 文件管理**
- 导入设计按钮
- 保存按钮  
- 当前设计文件列表
- 类似墨刀的文件管理功能

**🖼️ 资产库**
- 图片资源网格展示
- 图标库
- 字体文件
- 样式库
- 支持拖拽到画布

**🧩 组件库**
- 基础组件（按钮、文本、输入框等）
- 布局组件（容器、网格等）
- 高级组件（表格、图表等）
- 折叠式分类展示
- 支持拖拽到画布

#### 下半部分：图层树 (300px)
- 🌳 图层面板
- 层级展示当前设计的组件树
- 展开/折叠控制
- 选择、编辑、删除、复制操作
- 拖拽重排序功能

### 3. 中间画布区域

#### 画布工具栏 (40px)
**左侧：面包屑导航**
- 显示当前选中组件的路径

**右侧：缩放控制**
- 缩小 / 百分比 / 放大 / 重置

#### 设计画布
- 响应式预览（桌面/平板/手机）
- 支持拖拽组件添加
- 组件选择和编辑
- 缩放和平移

### 4. 右侧属性面板 (280px)

- ⚙️ 属性编辑
- 基础属性（名称、类型、ID）
- 样式属性（尺寸、颜色、字体等）
- 布局属性（对齐、间距等）
- 组件特定属性

## 🎨 视觉设计规范

### 颜色方案
```scss
// 主色调
$primary-color: #409eff;
$dark-bg: #2c3e50;

// 面板背景
$panel-bg: #ffffff;
$border-color: #e4e7ed;

// 文字颜色
$text-primary: #303133;
$text-secondary: #606266;
$text-placeholder: #909399;
```

### 间距规范
- 面板padding: 12px
- 组件间距: 8px
- 按钮间距: 4-8px
- 边框圆角: 4-6px

### 尺寸规范
- 左侧面板: 280px (可调整至260px、240px响应式)
- 右侧面板: 280px
- 图层面板高度: 300px (可调整至250px)
- 按钮高度: 32px (small)

## 🚀 交互设计

### 拖拽交互
1. **组件拖拽**：从组件库拖拽到画布
2. **资产拖拽**：从资产库拖拽到画布
3. **图层拖拽**：在图层树中重排序

### 快捷键
- `Ctrl/Cmd + S`: 保存设计
- `Delete`: 删除选中组件
- `Ctrl/Cmd + Z`: 撤销 (规划中)
- `Ctrl/Cmd + C/V`: 复制粘贴 (规划中)

### 选择状态
- 画布中组件选中高亮
- 图层树同步选中状态
- 属性面板实时显示选中组件属性

## 📱 响应式适配

### 1440px以下
```scss
@media (max-width: 1440px) {
  .left-panel, .right-panel {
    width: 260px;
  }
}
```

### 1200px以下
```scss
@media (max-width: 1200px) {
  .left-panel, .right-panel {
    width: 240px;
  }
  .left-panel-bottom {
    height: 250px;
  }
}
```

## 🔄 与行业标准对比

### Figma布局特点
- ✅ 左侧：资产面板 + 图层面板
- ✅ 中间：画布区域
- ✅ 右侧：属性面板
- ✅ 顶部：工具栏

### 墨刀布局特点
- ✅ 左上：文件管理
- ✅ 左下：组件库/图层
- ✅ 中间：设计画布
- ✅ 右侧：属性编辑

### 蓝湖布局特点
- ✅ 三栏式布局
- ✅ 层级树在左侧
- ✅ 属性面板在右侧

## 📈 用户体验优势

1. **熟悉的布局**：符合设计师已有使用习惯
2. **高效的工作流**：左侧选择→中间设计→右侧调整
3. **清晰的信息架构**：文件/资产/组件分离，图层独立
4. **响应式适配**：适应不同屏幕尺寸
5. **一致的交互**：拖拽、快捷键等符合行业标准

## 🛠️ 技术实现

### 组件层次
```
ConverterView.vue (主容器)
├── TopMenubar (顶部菜单栏)
├── LeftPanel (左侧面板)
│   ├── FilesTab (文件标签)
│   ├── AssetsTab (资产标签)
│   ├── ComponentsTab (组件标签)
│   └── LayersPanel (图层面板)
├── CanvasArea (画布区域)
│   ├── CanvasToolbar (画布工具栏)
│   └── DesignCanvas (设计画布)
└── RightPanel (右侧面板)
    └── PropertyPanel (属性面板)
```

### 状态管理
- `currentDesign`: 当前设计树
- `selectedNode`: 选中的组件
- `previewMode`: 预览模式 (desktop/tablet/mobile)
- `canvasZoom`: 画布缩放比例
- `leftActiveTab`: 左侧激活标签

### 核心功能
- 拖拽添加组件
- 图层树操作
- 属性实时编辑
- 画布缩放和导航
- 设备预览切换

这个新的布局设计完全符合行业标准，将大大降低用户的学习成本，提供更专业的UX设计体验。
