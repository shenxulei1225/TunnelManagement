## 🎨 整体页面布局

### 集成方案：UI转换器页面扩展
现有资源导入功能已整合到 `converter/index.vue` 页面中：

```
UI转换器页面 (完整转换器)
├── 导航栏 (固定顶部)
├── 步骤指示器 (水平步骤条)
│   ├── 步骤1: 导入设计 ✅ 当前
│   ├── 步骤2: 预览解析
│   ├── 步骤3: 配置选项
│   └── 步骤4: 生成代码
└── 主内容区域 (动态切换)
    └── 导入设计面板 (当前激活)
        ├── 资源类型选择区
        ├── 导入方式配置区
        ├── 进度监控区
        └── 错误处理区
```

## 📱 响应式设计

### 桌面端布局 (>= 1200px)
- 三栏布局：资源选择器 | 主内容 | 详情面板
- 固定宽度侧边栏
- 自适应主内容区

### 平板端布局 (768px - 1199px)
- 两栏布局：主内容 | 可折叠详情面板
- 粘性头部导航
- 滑动详情面板

### 移动端布局 (<= 767px)
- 单栏布局：垂直堆叠
- 底部弹出详情面板
- 手势导航支持
