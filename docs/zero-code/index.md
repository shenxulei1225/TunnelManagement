## 🎯 核心功能

### 1. 可视化页面设计器
- **拖拽式设计**: 用户可以直接拖拽组件到设计区域
- **实时预览**: 设计过程中可以实时预览效果
- **属性配置**: 右侧面板可以配置组件的各种属性
- **组件库**: 提供丰富的组件库（基础组件、表单组件、数据组件、布局组件）

### 2. 自动代码生成
- **Vue组件代码**: 自动生成完整的Vue组件代码
- **路由配置**: 自动生成路由配置
- **菜单配置**: 自动生成菜单配置
- **样式代码**: 自动生成CSS样式

### 3. 自动打包上传
- **一键生成**: 点击"生成并上传"按钮
- **自动构建**: 自动执行前端构建
- **自动部署**: 可选择自动部署到服务器
- **构建状态**: 实时显示构建进度和状态

## 🏗️ 技术架构

### 前端架构
```
PageDesigner.vue          # 主设计器组件
├── ComponentPanel        # 组件面板
├── DesignCanvas         # 设计画布
├── PropertyPanel        # 属性面板
└── PreviewDialog        # 预览对话框
```

### 后端架构
```
PageDesignerService       # 页面设计器服务
├── 保存页面设计
├── 生成页面代码
├── 执行构建流程
└── 部署页面
```

### 构建系统
```
build-with-generated.js   # 构建脚本
├── 收集生成的页面
├── 生成路由配置
├── 生成菜单配置
└── 执行构建
```

## 🔄 开发流程

### 1. 设计阶段
- 用户通过可视化界面设计页面
- 拖拽组件到设计区域
- 配置组件属性和样式
- 实时预览页面效果

### 2. 生成阶段
- 系统自动生成Vue组件代码
- 生成路由和菜单配置
- 验证代码的正确性和安全性
- 保存到文件系统

### 3. 构建阶段
- 收集所有生成的页面
- 更新路由和菜单配置
- 执行前端构建流程
- 监控构建状态和进度

### 4. 部署阶段
- 将构建结果同步到服务器
- 更新应用配置
- 重启应用服务
- 验证部署结果

## 🚀 快速开始

### 1. 访问页面设计器
```
http://localhost:3000/examples/page-designer
```

### 2. 设计页面
1. 从左侧组件库拖拽组件到设计区域
2. 在右侧属性面板配置组件属性
3. 实时预览页面效果

### 3. 生成页面
1. 点击"生成并上传"按钮
2. 填写页面配置（页面名称、路径、菜单等）
3. 系统自动生成代码并上传
4. 自动执行构建流程

### 4. 部署页面
1. 构建完成后可选择自动部署
2. 页面自动添加到菜单中
3. 可以立即访问新页面
