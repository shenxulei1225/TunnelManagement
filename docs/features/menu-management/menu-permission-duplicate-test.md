# 权限标识重复处理测试指南

## 测试目的

验证权限标识重复从**错误**改为**警告**的功能是否正常工作。

## 测试场景

### 场景1：权限重复警告显示
1. 创建第一个菜单，权限标识为：`system:field-def:list`
2. 创建第二个菜单，使用相同权限标识：`system:field-def:list`
3. 验证系统显示警告而非错误

### 场景2：权限重复可以提交
1. 在菜单表单中输入已存在的权限标识
2. 验证表单可以正常提交
3. 验证菜单创建成功

## 测试步骤

### 步骤1：准备测试数据
```sql
-- 检查现有权限标识
SELECT id, name, permission FROM system_menu WHERE permission = 'system:field-def:list';
```

### 步骤2：创建测试菜单
1. 访问菜单管理页面
2. 点击"新增"按钮
3. 填写以下测试数据：
   ```
   菜单名称: 测试权限重复页面
   父菜单: 系统管理
   菜单类型: 菜单
   组件名称: TestPermissionDuplicate
   组件路径: test/permission/duplicate
   路由路径: test-permission
   权限标识: system:field-def:list  ← 使用已存在的权限
   图标: ep:test
   ```

### 步骤3：验证警告显示
观察是否出现以下警告信息：
```
⚠️ 警告：权限标识"system:field-def:list"已被菜单"字段属性管理"使用。
这在以下情况下是合理的：
- 同一功能的不同视图
- 测试和正式页面  
- 权限级别相同的功能
如果您确认这是预期的，可以继续使用。
```

### 步骤4：验证可以提交
1. 点击"创建"按钮
2. 验证菜单创建成功
3. 验证在菜单列表中能看到新创建的菜单

### 步骤5：验证权限重复说明
1. 检查是否显示"关于权限标识重复"的说明卡片
2. 验证说明内容是否包含合理使用场景
3. 验证用户能理解权限重复是允许的

## 预期结果

### ✅ 正确行为
- 权限重复显示为警告（橙色）而非错误（红色）
- 表单可以正常提交
- 显示详细的权限重复说明
- 用户能理解何时可以使用重复权限

### ❌ 错误行为
- 权限重复仍然显示为错误
- 表单无法提交
- 没有显示权限重复说明
- 用户不知道是否可以使用重复权限

## 测试案例

### 案例1：合理的权限重复
```javascript
// 原始菜单
{
  name: "字段属性管理",
  permission: "system:field-def:list"
}

// 新建菜单（合理重复）
{
  name: "字段属性查看",
  permission: "system:field-def:list"  // 同一功能的不同视图
}
```

### 案例2：测试页面权限重复
```javascript
// 正式页面
{
  name: "用户管理",
  permission: "system:user:list"
}

// 测试页面（合理重复）
{
  name: "用户管理测试",
  permission: "system:user:list"  // 测试页面复用权限
}
```

## 回归测试

确保其他验证仍然正常工作：

### 组件名称重复（仍应阻止）
```javascript
{
  componentName: "FieldDef"  // 如果已存在，应该阻止提交
}
```

### 菜单名称重复（仍应阻止）
```javascript
{
  name: "字段属性管理",  // 同一父菜单下重复，应该阻止
  parentId: 1
}
```

## 清理测试数据

测试完成后，删除测试菜单：
```sql
DELETE FROM system_menu WHERE name = '测试权限重复页面';
```
