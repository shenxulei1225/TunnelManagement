# 区域管理页面 - UniversalTreeView 测试配置

## 概述

区域管理页面已经集成了新的 UniversalTreeView 组件，支持新旧树形组件的切换功能。用户可以通过页面上的切换按钮对比两种实现的效果。

## 功能特性

### 原始表格组件
- 基于 el-table 的树形表格
- 支持展开/折叠功能
- 条纹显示，悬停高亮
- 固定操作列

### 新 UniversalTreeView 组件
- 基于 el-tree 的统一树形组件
- 模拟表格样式布局
- 保持原有的视觉效果
- 支持搜索、展开/折叠等功能

## 切换功能

页面提供了一个切换按钮：
- **绿色按钮**："切换到新树形组件" - 当前使用原始表格
- **橙色按钮**："切换到原始表格" - 当前使用新树形组件

## 菜单配置参数

由于这是在现有页面上的功能测试，无需额外的菜单配置。

### 测试访问路径
- 页面路径：`/system/region`
- 组件名称：`SystemRegion`
- 权限标识：`system:region:query`

## 样式对比

### 表格头部
两种实现都保持一致的表格头部：
- 区域名称（左对齐，自适应宽度）
- 状态（居中，100px 宽度）
- 操作（居中，150px 宽度）

### 行样式
- 行高：48px
- 悬停效果：浅灰色背景
- 选中效果：主色调浅色背景
- 边框：浅色分隔线

### 操作按钮
- 编辑：蓝色链接按钮
- 删除：红色链接按钮
- 按钮间距：8px

## 技术实现

### 关键组件
```typescript
// 原始实现
<el-table>
  <!-- 表格列定义 -->
</el-table>

// 新实现
<UniversalTreeView>
  <template #default="{ data }">
    <div class="table-row-like">
      <!-- 自定义行内容 -->
    </div>
  </template>
</UniversalTreeView>
```

### 样式映射
```scss
// 模拟表格行样式
.table-row-like {

```
