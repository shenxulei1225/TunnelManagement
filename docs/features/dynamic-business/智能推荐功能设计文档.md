# 动态业务智能推荐功能设计文档

> **功能模块**: 动态业务智能推荐系统  
> **目标**: 提供基于场景模板和用户行为的智能字段推荐  
> **维护团队**: 全栈开发团队

## 📋 功能概述

动态业务智能推荐系统旨在解决用户在创建业务模型时"脑补字段"的困难，通过混合式智能推荐算法，结合场景模板和用户历史行为，为用户提供个性化的字段推荐服务。

## 🎯 核心设计理念

### 方案三：混合式智能推荐

```
业务创建 → 智能推荐 → 场景模板选择 → 字段智能匹配 → 界面预览 → 微调优化
```

**优势：**
- **降低认知负担** - 通过场景模板提供起点
- **保持灵活性** - 用户可以自定义调整
- **提高效率** - 智能推荐减少重复工作
- **支持学习** - 系统可以从用户行为中学习优化推荐

#### 3. 用户行为表 (dynamic_user_behavior)
```sql
CREATE TABLE dynamic_user_behavior (
    id BIGINT NOT NULL AUTO_INCREMENT COMMENT '行为ID',

    field_usage JSON COMMENT '字段使用情况',
    operation_type VARCHAR(32) NOT NULL COMMENT '操作类型（create:创建，update:更新，view:查看）',
```

## 🎨 用户交互流程

### 1. 业务创建流程

```
用户选择业务类型 → 系统推荐场景模板 → 用户选择模板 → 系统推荐字段 → 用户调整字段 → 实时预览 → 确认创建
```

### 2. 智能推荐算法

#### 场景模板推荐
- 基于业务类型匹配相关模板
- 按模板权重和用户偏好排序
- 支持模板状态过滤（只推荐启用的模板）

#### 字段推荐策略
1. **模板推荐** - 基于场景模板的预设字段
2. **用户行为推荐** - 基于用户历史使用习惯
3. **智能匹配** - 基于业务场景的规则匹配
4. **权重计算** - 综合多种因素计算推荐权重

#### 用户行为分析
```java
// 分析用户行为，生成推荐字段
Map<String, Integer> fieldUsageCount = new HashMap<>();
for (DynamicUserBehaviorDO behavior : behaviors) {
    Map<String, Object> fieldUsage = objectMapper.readValue(
            behavior.getFieldUsage(), 
            new TypeReference<Map<String, Object>>() {}
    );
    
    // 统计字段使用频率
    for (String fieldCode : fieldUsage.keySet()) {
        fieldUsageCount.merge(fieldCode, 1, Integer::sum);
    }
}
```

## 📚 使用指南

### 1. 开发人员指南

#### 添加新的场景模板
1. 在数据库中插入模板数据
2. 配置推荐字段和布局
3. 设置验证规则
4. 测试模板功能

#### 扩展字段类型
1. 在FieldTypeEnum中添加新类型
2. 在预览服务中添加对应的HTML生成逻辑
3. 更新字段配置验证规则

### 2. 用户使用指南

#### 创建业务模型
1. 选择业务类型（如：巡检、设备管理等）
2. 选择场景模板（如：日常巡检、重点巡检等）
3. 查看系统推荐的字段
4. 根据需要进行字段调整
5. 预览界面效果
6. 确认并创建业务模型

#### 个性化推荐
1. 系统会记录用户的操作行为
2. 基于历史行为提供个性化推荐
3. 用户可以查看推荐理由
4. 支持手动调整推荐结果
