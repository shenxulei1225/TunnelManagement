# 动态业务智能推荐用户使用指南

> **版本**: v1.0.0  
> **更新时间**: 2024-01-28  
> **适用用户**: 业务管理员、系统管理员

## 📋 功能概述

动态业务智能推荐系统帮助您快速创建业务模型，通过智能推荐算法为您提供个性化的字段建议，让您无需"脑补字段"，轻松完成业务配置。

## 🎯 核心优势

### 1. 降低认知负担
- 通过场景模板提供起点，无需从零开始
- 系统推荐相关字段，减少思考成本
- 实时预览效果，所见即所得

### 2. 保持灵活性
- 支持自定义字段调整
- 可以添加、删除、修改推荐字段
- 支持多种字段类型和配置

### 3. 提高效率
- 智能推荐减少重复工作
- 一键应用模板配置
- 批量字段操作支持

### 4. 支持学习
- 系统记录您的使用习惯
- 基于历史行为提供个性化推荐
- 推荐算法持续优化

## 🚀 快速开始

### 第一步：选择业务类型

1. 登录系统后，进入"动态业务管理"
2. 点击"创建业务模型"
3. 在业务类型下拉框中选择您的业务类型：
   - **巡检管理** - 适用于设备巡检、安全巡检等
   - **设备管理** - 适用于设备维护、设备档案等
   - **客户管理** - 适用于客户信息、客户服务等
   - **项目管理** - 适用于项目跟踪、任务管理等

### 第二步：选择场景模板

系统会根据您选择的业务类型，推荐相关的场景模板：

#### 巡检管理场景模板
- **日常巡检** - 适用于常规巡检任务
- **重点巡检** - 适用于重要设备巡检
- **专项巡检** - 适用于特定项目巡检

#### 设备管理场景模板
- **设备维护** - 适用于设备保养、维修
- **设备档案** - 适用于设备信息管理
- **设备监控** - 适用于设备状态监控

### 第三步：查看字段推荐

选择场景模板后，系统会为您推荐相关字段：

#### 日常巡检推荐字段
- **巡检日期** (date) - 记录巡检时间
- **巡检人员** (string) - 记录巡检责任人
- **巡检结果** (enum) - 记录巡检状态
- **巡检备注** (textarea) - 记录巡检发现的问题

#### 重点巡检推荐字段
- **巡检日期** (date) - 记录巡检时间
- **巡检人员** (string) - 记录巡检责任人
- **巡检结果** (enum) - 记录巡检状态
- **巡检优先级** (enum) - 设置巡检重要程度
- **巡检备注** (textarea) - 记录巡检发现的问题

### 第四步：调整字段配置

您可以根据实际需求调整推荐字段：

#### 添加字段
1. 点击"添加字段"按钮
2. 选择字段类型（文本、数字、日期等）
3. 填写字段名称和编码
4. 设置字段属性（是否必填、默认值等）

#### 修改字段
1. 点击字段右侧的"编辑"按钮
2. 修改字段名称、类型或属性
3. 保存修改

#### 删除字段
1. 点击字段右侧的"删除"按钮
2. 确认删除操作

### 第五步：预览界面效果

调整字段后，可以实时预览界面效果：

#### 列表页预览
- 显示字段列表和示例数据
- 支持排序和筛选功能
- 提供操作按钮（新增、编辑、删除）

#### 表单页预览
- 显示字段输入表单
- 支持字段验证规则
- 提供保存和取消按钮

#### 详情页预览
- 显示字段详细信息
- 支持字段分组显示
- 提供编辑和返回按钮

### 第六步：确认创建

1. 检查预览效果是否符合预期
2. 查看验证结果，确保配置正确
3. 点击"确认创建"按钮
4. 系统自动生成菜单和权限配置

## 🎨 高级功能

### 1. 个性化推荐

系统会记录您的使用习惯，提供个性化推荐：

#### 查看推荐理由
- 每个推荐字段都有推荐理由
- 点击"查看详情"了解推荐原因
- 基于模板推荐：根据场景模板预设
- 基于习惯推荐：根据您的使用历史

#### 调整推荐权重
- 系统会根据您的使用频率调整推荐权重
- 经常使用的字段会获得更高权重
- 新创建的字段会逐渐学习您的偏好

### 2. 智能字段匹配

系统提供智能字段匹配功能：

#### 基于业务场景匹配
- 根据业务类型和场景类型智能匹配字段
- 匹配度显示字段的适用程度
- 推荐度标识是否建议使用该字段

#### 字段类型建议
- 系统会根据字段用途建议合适的字段类型
- 日期类信息建议使用date类型
- 选项类信息建议使用enum类型
- 长文本信息建议使用textarea类型

### 3. 配置验证

系统提供配置验证功能：

#### 实时验证
- 字段配置实时验证
- 显示错误、警告和建议信息
- 帮助您及时发现配置问题

#### 验证规则
- **必填字段检查** - 确保必填字段有名称
- **字段编码唯一性** - 确保字段编码不重复
- **字段类型检查** - 确保字段类型有效
- **主键字段建议** - 建议添加主键字段

## 📊 字段类型详解

### 基础字段类型

| 字段类型 | 描述 | 适用场景 | 示例 |
|---------|------|---------|------|
| string | 文本输入 | 名称、描述等 | 巡检人员、设备名称 |
| number | 数字输入 | 数量、金额等 | 巡检次数、维护费用 |
| date | 日期选择 | 日期信息 | 巡检日期、维护日期 |
| datetime | 日期时间 | 时间戳信息 | 创建时间、更新时间 |
| textarea | 长文本 | 详细描述 | 巡检备注、问题描述 |
| select | 下拉选择 | 选项信息 | 巡检结果、设备状态 |
| enum | 枚举选择 | 固定选项 | 优先级、类型分类 |
| image | 图片上传 | 图片信息 | 设备照片、现场图片 |

### 高级字段类型

| 字段类型 | 描述 | 适用场景 | 示例 |
|---------|------|---------|------|
| file | 文件上传 | 文档信息 | 巡检报告、维护手册 |
| rich_text | 富文本 | 格式化文本 | 详细说明、操作指南 |
| cascader | 级联选择 | 层级数据 | 地区选择、分类选择 |
| reference | 引用关联 | 关联数据 | 关联设备、关联人员 |

## 🔧 配置技巧

### 1. 字段命名规范

#### 编码命名
- 使用英文小写字母和下划线
- 避免使用特殊字符和空格
- 建议使用有意义的名称
- 示例：`inspection_date`、`device_name`

#### 显示名称
- 使用中文名称，便于理解
- 名称要简洁明了
- 避免重复和歧义
- 示例：`巡检日期`、`设备名称`

### 2. 字段配置优化

#### 必填字段设置
- 核心业务字段设置为必填
- 非核心字段可以设为非必填
- 考虑用户体验，不要设置过多必填字段

#### 默认值设置
- 为常用字段设置合理的默认值
- 日期字段可以设置当前日期
- 状态字段可以设置默认状态

#### 验证规则配置
- 为数字字段设置范围限制
- 为文本字段设置长度限制
- 为日期字段设置格式验证

### 3. 布局配置技巧

#### 字段分组
- 相关字段放在一起
- 使用合理的列数布局
- 重要字段放在前面

#### 显示优化
- 长文本字段使用整行显示
- 短字段可以并排显示
- 根据字段重要性调整显示顺序

## ⚠️ 常见问题

### 1. 推荐字段不准确怎么办？

**解决方案：**
- 检查业务类型选择是否正确
- 尝试选择其他场景模板
- 查看基于用户行为的推荐
- 手动添加需要的字段

### 2. 预览效果不理想怎么办？

**解决方案：**
- 调整字段的显示类型
- 修改字段的布局配置
- 重新排列字段顺序
- 添加或删除相关字段

### 3. 验证出现错误怎么办？

**解决方案：**
- 检查必填字段是否填写完整
- 确保字段编码不重复
- 验证字段类型是否正确
- 按照建议信息进行调整

### 4. 如何提高推荐准确性？

**解决方案：**
- 多使用系统功能，让系统学习您的习惯
- 定期清理不需要的字段
- 为字段设置合理的属性
- 提供使用反馈
