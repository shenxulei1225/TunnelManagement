## 🔧 **常见问题排查**

### **问题1：页面显示"加载数据失败"**
**原因**：未登录或登录状态过期  
**解决**：重新登录系统

### **问题2：找不到测试页面菜单**
**原因**：菜单未创建或权限不足  
**解决**：
1. 手动输入URL：`http://localhost:81/#/test/enhanced-tree`
2. 或者执行菜单创建SQL脚本

### **问题3：API调用返回401错误**
**原因**：Token过期或未携带  
**解决**：刷新页面重新登录

### **问题4：数据为空**
**原因**：数据库表未初始化  
**解决**：检查数据库中是否有23条测试数据
