# 字段删除操作测试指南

## 🎯 测试目标

验证字段管理页面中删除操作能够根据当前显示模式智能切换行为：
- **全部字段页面**：删除字段 → 完全删除字段定义
- **已关联字段页面**：解除关联 → 只解除字段与分组的关联

## 📋 测试场景

### 场景1：全部字段页面删除
**前置条件**：
- 进入字段分级管理页面
- 左侧树选择"全部字段"或没有选择具体分组
- 右侧显示所有字段

**操作步骤**：
1. 点击任意字段卡片的"..."菜单
2. 查看删除选项文案：应显示"**删除字段**"
3. 点击"删除字段"
4. 确认弹窗内容应为：
   ```
   确定要彻底删除字段 "字段名" 吗？
   
   此操作将：
   • 完全删除该字段定义
   • 删除所有相关的分类关联
   • 删除所有使用该字段的数据
   
   ⚠️ 此操作不可恢复！
   ```
5. 确认按钮文案：**删除字段**
6. 确认删除后，字段应从系统中完全消失

**预期结果**：
- ✅ 按钮显示"删除字段"
- ✅ 提示内容明确说明是完全删除
- ✅ 确认按钮为红色警告样式
- ✅ 删除后字段完全消失

### 场景2：已关联字段页面解除关联
**前置条件**：
- 进入字段分级管理页面
- 左侧树选择具体的分组（如"设备"分组）
- 右侧显示该分组下的已关联字段

**操作步骤**：
1. 点击任意字段卡片的"..."菜单
2. 查看删除选项文案：应显示"**解除关联**"
3. 点击"解除关联"
4. 确认弹窗内容应为：
   ```
   确定要解除 字段 "字段名" 与 当前分类 的关联吗？
   
   此操作将：
   • 解除字段与分类的关联关系
   • 字段定义本身不会被删除
   • 可以重新关联到其他分类
   
   ✅ 此操作可以撤销
   ```
5. 确认按钮文案：**解除关联**
6. 确认解除后，字段从当前分组消失，但在"全部字段"中仍存在

**预期结果**：
- ✅ 按钮显示"解除关联"
- ✅ 提示内容明确说明只是解除关联
- ✅ 确认按钮为黄色警告样式
- ✅ 解除后字段只从当前分组消失，其他地方仍可见

### 场景3：表格视图测试
**操作步骤**：
1. 切换到表格视图
2. 重复场景1和场景2的测试
3. 验证表格中的删除按钮文案是否正确

**预期结果**：
- ✅ 表格视图中的按钮文案与卡片视图一致

## 🔧 API调用验证

### 删除字段API
```
DELETE /admin-api/system/field/delete?id=字段ID
```

### 解除关联API
```
DELETE /admin-api/system/field/unlink-hierarchy-group?fieldId=字段ID&hierarchyGroupId=分组ID
```

## 🐛 已知问题修复

1. **问题**：无论什么场景都显示"删除字段"
   **修复**：根据 `selectedHierarchyId` 状态动态切换按钮文案和操作类型

2. **问题**：分类管理和分组管理API混用
   **修复**：分组管理使用 `unlinkFieldHierarchyGroup` API

3. **问题**：用户对操作结果不明确
   **修复**：提供详细的确认提示和明确的按钮文案

## 💡 用户体验改进

1. **图标优化**：
   - 删除字段：🗑️ 垃圾桶图标（红色）
   - 解除关联：🔗💥 链接断开图标（橙色）

2. **颜色区分**：
   - 删除字段：`type="danger"` 红色
   - 解除关联：`type="warning"` 橙色

3. **快捷键支持**：
   - Delete键：根据当前模式执行对应操作
   - Ctrl+Delete：强制删除字段（无论什么模式）
