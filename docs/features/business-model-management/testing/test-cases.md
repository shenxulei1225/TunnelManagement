# 业务模型管理 - 测试用例

## 测试概述

本文档包含业务模型管理模块的完整测试用例，涵盖功能测试、权限测试、边界测试和异常测试。

## 测试环境

- **后端服务**: `http://localhost:48080`
- **数据库**: MySQL 8.0
- **测试工具**: HTTP Client (IntelliJ IDEA)
- **测试数据**: 见下方测试数据准备

## 测试数据准备

