# 模板生成器功能说明

## 📋 功能概述

模板生成器是一个基于模板选择和参数配置的页面自动生成功能，支持选择现有的页面模板（如拖拽分类页面模板），通过配置参数生成具体的页面实例。

## 🎯 核心设计理念

### 设计思路
1. **模板选择** - 选择现有的页面模板作为生成基础
2. **参数配置** - 在自动生成页面上配置相关参数
3. **页面生成** - 基于模板和参数生成具体的页面实例
4. **功能实现** - 实现相关的业务功能，如设备按区域分类

### 与页面生成器的结合
- 利用现有的页面生成器功能
- 通过模板系统实现快速页面创建
- 支持多种页面类型和业务场景

## 📦 可用模板

### 1. 拖拽分类页面模板
- **功能描述**: 支持拖拽排序的分类管理页面
- **适用场景**: 设备按区域分类、产品分类管理等
- **核心特性**: 
  - 拖拽排序功能
  - 分类层级管理
  - 设备状态显示
  - 搜索和筛选

### 2. 数据表格页面模板
- **功能描述**: 标准的数据表格页面
- **适用场景**: 数据管理、列表展示等
- **核心特性**:
  - 增删改查功能
  - 搜索和分页
  - 批量操作
  - 数据导出

### 3. 表单页面模板
- **功能描述**: 动态表单页面
- **适用场景**: 数据录入、配置管理等
- **核心特性**:
  - 多种表单控件
  - 表单验证
  - 动态字段配置
  - 文件上传

### 4. 仪表板页面模板
- **功能描述**: 数据可视化仪表板
- **适用场景**: 数据监控、统计分析等
- **核心特性**:
  - 统计卡片
  - 图表展示
  - 实时数据
  - 告警信息

## ⚙️ 配置参数

### 基本信息配置
- **页面名称**: 生成的页面名称
- **页面描述**: 页面功能描述
- **菜单路径**: 页面访问路径
- **菜单图标**: 菜单显示图标

### 数据源配置
- **数据源类型**: 静态数据、API接口、数据库表
- **数据表名**: 数据库表名（数据库类型）
- **API地址**: 接口地址（API类型）

### 字段配置
- **字段名**: 数据库字段名
- **显示名**: 页面显示名称
- **字段类型**: 文本、数字、日期、选择、开关等
- **必填**: 是否必填字段
- **搜索**: 是否支持搜索

### 功能配置
- **启用功能**: 搜索、新增、编辑、删除、导出、导入等
- **页面权限**: 访问权限配置
- **排序字段**: 默认排序字段

## 🔄 工作流程

### 1. 模板选择阶段
1. 用户进入模板生成器页面
2. 浏览可用的页面模板
3. 选择适合的模板
4. 查看模板预览效果

### 2. 参数配置阶段
1. 配置基本信息（页面名称、描述等）
2. 配置数据源（数据来源、表名等）
3. 配置字段信息（字段名、类型、验证等）
4. 配置功能选项（搜索、增删改查等）

### 3. 预览确认阶段
1. 实时预览生成的页面效果
2. 验证配置参数的正确性
3. 调整配置参数（如需要）

### 4. 页面生成阶段
1. 调用后端生成API
2. 生成页面代码和配置
3. 自动创建菜单和权限
4. 部署到系统中

## 🔧 技术实现

### 前端技术栈
- **Vue 3**: 响应式框架
- **TypeScript**: 类型安全
- **Element Plus**: UI组件库
- **Vue Router**: 路由管理

### 核心组件
- **模板选择器**: 展示可用模板列表
- **参数配置器**: 动态表单配置
- **预览组件**: 实时预览效果
- **步骤导航**: 引导用户完成配置

### API接口
```typescript
// 获取可用模板
GET /dynamic/templates

// 生成页面
POST /dynamic/generate-page

// 获取生成历史
GET /dynamic/generation-history

// 预览页面
GET /dynamic/generated-page/{pageId}/preview
```

## 🚀 使用指南

### 快速开始
1. 进入"动态业务" → "模板生成器"
2. 选择适合的页面模板
3. 配置页面参数
4. 预览生成效果
5. 确认并生成页面

### 配置示例
以"设备按区域分类"为例：
1. 选择"拖拽分类页面"模板
2. 配置页面名称为"设备分类管理"
3. 设置数据源为设备表
4. 配置字段：区域名称、设备数量、状态等
5. 启用搜索、新增、编辑功能
6. 生成页面实例
