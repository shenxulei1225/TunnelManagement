# Figma导入功能使用指南

## 🎯 功能概述

Universal X Designer现已支持从Figma直接导入设计文件，自动转换为可编辑的组件结构。该功能通过Figma官方API实现，支持完整的设计树转换和资源提取。

## ✨ 主要特性

### 1. 完整的API集成
- ✅ Figma REST API v1支持
- ✅ 访问令牌验证
- ✅ 错误处理和友好提示
- ✅ 文件ID自动提取

### 2. 智能设计转换
- ✅ 自动识别组件类型（Button、Text、Image等）
- ✅ 样式属性完整转换（颜色、尺寸、边框、字体等）
- ✅ 布局信息保留（位置、约束、Auto Layout）
- ✅ 图片资源自动导出

### 3. 高级选项
- ✅ 可选图片导出（PNG/JPG/SVG）
- ✅ 多倍图支持（0.5x-3x）
- ✅ 渐变和效果转换
- ✅ 组件层级保持

## 🚀 使用步骤

### 第一步：准备Figma访问令牌

1. 访问 [Figma个人设置](https://www.figma.com/settings)
2. 滚动到"Personal access tokens"部分
3. 点击"Create new token"
4. 输入描述（如"Universal X Designer"）
5. 复制生成的令牌（保密存储）

### 第二步：获取Figma文件URL

1. 在Figma中打开目标设计文件
2. 复制浏览器地址栏中的URL
3. URL格式：`https://www.figma.com/file/{文件ID}/...`

### 第三步：在UX设计器中导入

1. 打开UX设计器页面
2. 点击顶部工具栏的"导入"按钮
3. 选择"🎨 Figma"标签页
4. 填写表单：
   - **文件URL**: 粘贴Figma文件链接
   - **访问令牌**: 粘贴个人访问令牌
5. 配置高级选项（可选）：
   - 是否导出图片
   - 图片格式选择
   - 图片缩放倍数
6. 点击"开始导入"

### 第四步：查看导入结果

- 导入成功后，设计会自动显示在画布中
- 左侧图层面板显示组件层级
- 右侧属性面板可编辑组件属性
- 查看导入统计和警告信息

## 📋 支持的Figma节点类型

| Figma节点 | 转换组件 | 支持程度 | 说明 |
|-----------|----------|----------|------|
| RECTANGLE | Button | ✅ 完全支持 | 矩形转换为按钮组件 |
| TEXT | Text | ✅ 完全支持 | 文本样式完整保留 |
| FRAME | CanvasContainer | ✅ 完全支持 | 框架转换为容器 |
| GROUP | CanvasContainer | ✅ 完全支持 | 组转换为容器 |
| VECTOR | Image | ✅ 部分支持 | 矢量图转换为图片 |
| ELLIPSE | Image | ✅ 部分支持 | 椭圆转换为图片 |
| INSTANCE | UserWidget | ✅ 完全支持 | 组件实例 |
| COMPONENT | UserWidget | ✅ 完全支持 | 主组件 |
| LINE | Image | ⚠️ 基础支持 | 线条转换为图片 |

## 🎨 样式转换支持

### 完全支持的样式
- ✅ 尺寸（width, height）
- ✅ 位置（x, y坐标）
- ✅ 背景颜色（纯色、渐变）
- ✅ 边框（颜色、宽度、圆角）
- ✅ 字体（大小、粗细、颜色、行高）
- ✅ 透明度和混合模式
- ✅ 阴影效果

### 部分支持的样式
- ⚠️ 复杂渐变（转换为简单渐变）
- ⚠️ 高级效果（模糊、发光等）
- ⚠️ 图片填充（需要手动处理）

### 布局转换
- ✅ 绝对定位
- ✅ Auto Layout（Flexbox）
- ✅ 约束系统
- ✅ 内边距和间距

## 🔧 配置选项说明

### 基础选项
- **文件URL**: Figma文件的完整链接
- **访问令牌**: 个人访问令牌，确保有文件读取权限

### 高级选项
- **导出图片**: 是否导出设计中的图片资源
- **图片格式**: PNG（透明）、JPG（体积小）、SVG（矢量）
- **图片缩放**: 控制导出图片的分辨率

## ⚠️ 注意事项

### 权限要求
- 访问令牌必须有目标文件的读取权限
- 私有文件需要相应的团队访问权限

### 性能考虑
- 大型设计文件导入时间较长
- 图片导出会增加处理时间
- 建议优化设计文件层级结构

### 兼容性
- 支持Figma最新版本格式
- 部分高级功能可能需要降级处理
- 建议使用标准组件和样式

## 🐛 常见问题

### Q: 提示"访问令牌无效"
**A**: 检查令牌是否正确，是否有文件访问权限

### Q: 导入后组件位置不正确
**A**: Figma使用绝对定位，可能需要手动调整布局

### Q: 部分组件显示为"未知类型"
**A**: 复杂组件可能无法识别，可手动修改组件类型

### Q: 图片无法正常显示
**A**: 检查图片导出设置，确保网络可访问图片URL
