# Figma设计令牌导入指南

## 🎯 什么是设计令牌

设计令牌（Design Tokens）是设计系统中用于存储设计决策的原子级数据，包括颜色、字体、间距、阴影等可复用的设计属性。

## 📊 支持的设计令牌格式

### 标准令牌格式
```json
[
  {
    "Primary Color": {
      "value": "#3366FF"
    }
  },
  {
    "Secondary Color": {
      "value": "#6C757D"
    }
  },
  {
    "Background": {
      "value": "#FFFFFF"
    }
  }
]
```

### 您的数据格式（已支持）
```json
[
  {
    "Content": {
      "value": "#FFFFFF"
    }
  },
  {
    "Chrome browser bar": {
      "value": "#FEF7FF"
    }
  },
  {
    "Compact media player": {
      "value": "#FEF7FF"
    }
  }
]
```

## 🔧 导入步骤

### 1. 准备设计令牌数据
确保您的JSON数据符合以下结构：
- 每个令牌是一个对象
- 对象包含一个键值对，键是令牌名称
- 值是包含`value`属性的对象

### 2. 导入到系统
1. **点击导入按钮**: 在工具栏点击"导入设计"按钮
2. **选择平台**: 选择"Figma"平台
3. **选择导入方式**: 选择"文件上传"
4. **上传文件**: 选择您的设计令牌JSON文件
5. **开始导入**: 点击"开始导入"按钮

### 3. 导入结果
系统会自动创建一个包含所有设计令牌的可视化容器：
- **令牌名称**: 显示每个令牌的名称
- **颜色预览**: 对于颜色令牌，显示颜色方块
- **令牌值**: 显示具体的数值

## 🔄 支持的令牌类型

### 颜色令牌
```json
{
  "Primary Blue": {
    "value": "#3366FF"
  }
}
```
- 自动识别十六进制颜色值
- 显示颜色预览块
- 支持RGB、RGBA格式

### 文本令牌
```json
{
  "Button Text": {
    "value": "点击按钮"
  }
}
```
- 显示文本内容
- 可用于按钮文本、标签等

### 数值令牌
```json
{
  "Border Radius": {
    "value": "8px"
  }
}
```
- 用于尺寸、间距等数值
- 保持原始单位

## ⚙️ 高级功能

### 令牌分组
如果您的令牌有层级结构：
```json
[
  {
    "Colors/Primary": {
      "value": "#3366FF"
    }
  },
  {
    "Colors/Secondary": {
      "value": "#6C757D"
    }
  }
]
```

系统会自动处理层级命名，便于组织管理。

### 批量导入
支持一次导入大量设计令牌：
- 单个文件最多支持1000个令牌
- 自动布局和排列
- 智能容器大小调整

## 🛠️ 导入后操作

### 1. 编辑令牌组件
- **修改名称**: 双击令牌名称进行编辑
- **调整位置**: 拖拽移动令牌位置
- **修改样式**: 在属性面板调整外观

### 2. 应用到其他组件
- **复制颜色值**: 点击颜色预览块复制色值
- **创建色彩板**: 将令牌组织为色彩板组件
- **生成样式指南**: 导出为样式指南文档

### 3. 导出和分享
- **导出CSS变量**: 生成CSS自定义属性
- **导出JSON**: 保持原始令牌格式
- **生成文档**: 创建设计系统文档

## 🔍 故障排除

### 常见错误及解决方案

#### 错误: "平台 figma 的数据格式验证失败"
**解决方案:**
1. 检查JSON格式是否正确
2. 确保每个令牌都有`value`属性
3. 验证文件编码为UTF-8

#### 导入后组件不显示
**解决方案:**
1. 检查画布缩放比例
2. 使用"适应画布"功能(Ctrl+F)
3. 查看组件是否在可视区域外

#### 颜色预览不正确
**解决方案:**
1. 确认颜色值格式正确
2. 支持格式: #FFFFFF, rgb(255,255,255), rgba(255,255,255,1)
3. 检查颜色值是否有效

## 📋 最佳实践

### 1. 命名规范
```json
// ✅ 推荐
{
  "color-primary-500": { "value": "#3366FF" }
}

// ❌ 不推荐  
{
  "蓝色": { "value": "#3366FF" }
}
```

### 2. 分类组织
```json
[
  { "color-primary-100": { "value": "#E3F2FD" } },
  { "color-primary-500": { "value": "#2196F3" } },
  { "color-primary-900": { "value": "#0D47A1" } },
  { "spacing-xs": { "value": "4px" } },
  { "spacing-sm": { "value": "8px" } },
  { "spacing-md": { "value": "16px" } }
]
```

### 3. 版本管理
- 为设计令牌文件添加版本号
- 保持向后兼容性
- 记录变更历史
