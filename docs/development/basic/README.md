## 🚀 快速开始

### 新开发者必读清单

1. **📱 前端开发** → 优先阅读 [Element Plus 组件参考](element-plus-components-reference.md)
   - 了解项目使用的Element Plus版本特性
   - 学习正确的组件API使用方法
   - 避免常见的版本兼容性问题

2. **📋 页面开发** → 必须参考 [菜单配置模板](menu-template.md)
   - 每个新页面都需要创建对应菜单
   - 使用标准配置模板确保一致性
   - 注意多租户环境下的配置要求

3. **🛠️ 代码规范** → 遇到问题时查阅 [开发指导原则](development-guidelines.md)
   - TypeScript类型错误的标准解决方案
   - 组件接口定义的最佳实践
   - 开发过程中的常见陷阱和解决方案
