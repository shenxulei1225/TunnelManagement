## 📝 日常使用流程

### 🌅 每天开始工作时

#### 1. 检查当前模块状态
```markdown
📋 在项目主文档中找到你负责的模块：

| 模块名称 | 文件路径 | 状态 | 完成度 | 备注 |
|----------|----------|------|--------|------|
| **你的模块** | `ModuleName.ts` | 🔄 进行中 | 60% | 需要完成XX功能 |
```

#### 2. 更新状态为"进行中"
```markdown
# 如果状态不是"🔄 进行中"，请更新为：
| **你的模块** | `ModuleName.ts` | 🔄 进行中 | 60% | 开始今日开发 |
```

### 🔧 开发过程中

#### 1. 遇到问题时立即记录
```markdown
📋 在问题跟踪表中添加新记录：

| 问题ID | 描述 | 严重程度 | 状态 | 解决方案 |
|--------|------|----------|------|----------|
| ISS-XXX | [具体问题描述] | 🟡 中等 | 🔄 处理中 | [你的解决思路] |
```

#### 2. 完成子功能时更新完成度
```markdown
# 例如：从60%更新到75%
| **你的模块** | `ModuleName.ts` | 🔄 进行中 | 75% | 完成XX子功能 |
```

### 🎯 完成开发后

#### 1. 更新模块状态为"已完成"
```markdown
| **你的模块** | `ModuleName.ts` | ✅ 已完成 | 100% | 所有功能完成，已测试 |
```

#### 2. 如果创建了新页面，提供菜单配置
```javascript
// 使用标准菜单配置模板
{
  name: "[你的页面名称]",
  type: 2,
  sort: [排序号],
  parentId: [父菜单ID],
  path: "[路由路径]",
  icon: "[图标名称]",
  component: "[组件路径]",
  componentName: "[组件名]",
  permission: "[权限标识]",
  status: 0,
  visible: true,
  keepAlive: true,
  alwaysShow: false
}
```

#### 3. 更新总体进度
```markdown
# 如果你的模块完成，相应调整总体进度百分比
### 总体进度：18% (从15%更新到18%)
```

## 🔗 常用工具和快捷方式

### 📊 状态图标速查
- ✅ **已完成** - 功能实现完毕，已通过测试
- 🔄 **进行中** - 正在开发，功能部分完成
- 📋 **待开始** - 已计划，尚未开始开发
- ⚠️ **有问题** - 开发中遇到阻碍，需要解决
- 🚫 **已取消** - 计划取消或延期

### 🎨 严重程度图标
- 🔴 **严重** - 阻碍开发进展，必须立即解决
- 🟡 **中等** - 影响功能完整性，需要及时处理
- 🟢 **轻微** - 不影响核心功能，可以延后处理

## ❓ 常见问题解答

### Q: 我不确定如何评估完成度百分比？
A: 可以按功能点来计算：
- 规划了10个功能点，完成6个 = 60%
- 也可以按时间估算：预计5天完成，已用3天 = 60%

### Q: 问题解决后需要做什么？
A: 
1. 更新问题状态为"✅ 已解决"
2. 记录具体解决方案
3. 更新相关模块的完成度

### Q: 菜单配置的parentId如何获取？
A: 
1. 查看现有菜单管理系统
2. 找到对应的父级菜单
3. 获取其菜单ID作为parentId

### Q: 总体进度如何计算？
A: 
- 按模块权重计算：重要模块权重高
- 一般可按模块数量平均计算
- 例如：10个模块，8个完成 = 80%
