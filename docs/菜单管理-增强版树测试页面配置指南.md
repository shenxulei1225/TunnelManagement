## 🔧 **手工创建菜单步骤**

### **步骤1：创建父级目录菜单**
1. 进入系统管理 → 菜单管理
2. 点击"新增"按钮
3. 填入以上**父级菜单**的参数
4. 点击"确定"保存
5. **记录生成的菜单ID** (例如：1001)

### **步骤2：创建页面菜单**
1. 继续在菜单管理页面点击"新增"
2. 填入以上**子菜单**的参数
3. **父级菜单**选择上一步创建的"功能测试"
4. 点击"确定"保存
5. **记录生成的菜单ID** (例如：1002)

### **步骤3：创建权限按钮（可选）**
1. 分别创建4个权限按钮菜单
2. **父级菜单**选择步骤2创建的"增强版树组件测试"
3. **菜单类型**选择"按钮"
4. **显示状态**选择"隐藏"
5. 分别保存

### **步骤4：分配权限**
1. 进入系统管理 → 角色管理
2. 选择要授权的角色（如：超级管理员）
3. 点击"菜单权限"
4. 勾选新创建的菜单和权限
5. 点击"确定"保存

## 🚀 **自动化菜单创建API**

为了实现设计自动生成页面时通过调用菜单管理API接口自动创建，以下是相关API调用示例：

### **API调用顺序**

```typescript
// 1. 创建父级菜单
const parentMenuResponse = await menuApi.create({
  name: "功能测试",
  permission: "",
  type: 1,
  sort: 999,
  parentId: 0,
  path: "/test",
  icon: "TestTube",
  component: "",
  status: 0,
  visible: true,
  keepAlive: false,
  alwaysShow: true
})

const parentMenuId = parentMenuResponse.data.id

// 2. 创建页面菜单
const pageMenuResponse = await menuApi.create({
  name: "增强版树组件测试",
  permission: "test:enhanced-tree:page",
  type: 2,
  sort: 1,
  parentId: parentMenuId,
  path: "enhanced-tree", 
  icon: "TreeTable",
  component: "/test/enhanced-tree",
  componentName: "EnhancedTreeTest",
  status: 0,
  visible: true,
  keepAlive: true,
  alwaysShow: false
})

const pageMenuId = pageMenuResponse.data.id

// 3. 创建权限按钮
const permissions = [
  { name: "测试配置管理", permission: "test:enhanced-tree:config" },
  { name: "状态管理", permission: "test:enhanced-tree:state" },
  { name: "调试功能", permission: "test:enhanced-tree:debug" },
  { name: "导出功能", permission: "test:enhanced-tree:export" }
]

for (let i = 0; i < permissions.length; i++) {
  await menuApi.create({
    name: permissions[i].name,
    permission: permissions[i].permission,
    type: 3,
    sort: i + 1,
    parentId: pageMenuId,
    path: "",
    icon: "",
    component: "",
    status: 0,
    visible: false,
    keepAlive: false,
    alwaysShow: false
  })
}

// 4. 分配权限给超级管理员角色
await roleApi.assignMenus(adminRoleId, [
  parentMenuId, 
  pageMenuId, 
  ...permissionMenuIds
])
```

## 📊 **菜单创建验证清单**

### **✅ 创建后验证项目**

- [ ] **菜单显示**: 左侧导航栏能看到"功能测试"菜单
- [ ] **页面访问**: 点击"增强版树组件测试"能正常打开页面
- [ ] **URL正确**: 地址栏显示 `#/test/enhanced-tree`
- [ ] **权限控制**: 无权限用户无法访问
- [ ] **缓存功能**: 页面切换后状态保持
- [ ] **面包屑**: 显示正确的导航路径

### **🔍 常见问题排查**

**Q: 菜单不显示？**
- 检查菜单状态是否为"正常"
- 检查显示状态是否为"显示" 
- 检查当前用户是否有权限
- 检查父级菜单是否正确

**Q: 页面404错误？**
- 检查组件路径是否正确：`/test/enhanced-tree`
- 检查路由配置是否已加载
- 检查Vue组件文件是否存在

**Q: 权限控制不生效？**
- 检查权限标识是否正确
- 检查角色是否已分配菜单权限
- 检查用户是否属于对应角色
