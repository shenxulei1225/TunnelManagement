# Cheers Framework

## 项目介绍

Cheers Framework 是一个基于 Spring Boot 的轻量级开发框架,提供了多租户、数据权限、定时任务、Excel等常用功能模块。

## 模块说明

### 多租户模块 (cheers-framework-tenant)

提供多租户的数据隔离支持:

- 支持多种数据隔离级别:
  - 独立数据库
  - 共享数据库,独立Schema
  - 共享数据库,共享Schema,独立表
  - 共享数据库,共享Schema,共享表,独立字段

- 跨租户访问支持:
  - 支持超级管理员访问所有租户数据
  - 可配置允许跨租户访问的角色
  - 提供租户上下文管理

- Redis缓存隔离:
  - 支持租户级别的缓存隔离
  - 可配置忽略租户的缓存项
  - 优化缓存key生成策略

### 数据权限模块 (cheers-framework-data-permission)

提供灵活的数据权限控制:

- 规则组合功能:
  - 支持AND/OR组合方式
  - 动态创建和管理规则组合
  - 基于ID的规则组合管理

- 规则缓存优化:
  - 使用ConcurrentHashMap提升并发性能
  - 支持规则动态更新
  - 提供规则组合缓存

### 定时任务模块 (cheers-framework-job)

提供强大的任务调度功能:

- 任务分组管理:
  - 支持按业务分组管理任务
  - 提供分组任务批量操作
  - 分组级别的任务监控

- 任务依赖支持:
  - 支持配置任务间的依赖关系
  - 自动检查依赖任务状态
  - 保证任务按依赖顺序执行

- 执行流程优化:
  - 完善的任务生命周期管理
  - 支持任务暂停和恢复
  - 提供任务执行日志

### Excel模块 (cheers-framework-excel)

提供丰富的Excel处理功能:

- 单元格样式支持:
  - 内置多种预定义样式
  - 支持自定义样式配置
  - 提供标题、内容、数字、日期等样式

- 数据校验增强:
  - 支持下拉框数据校验
  - 自定义校验规则
  - 校验错误提示

- 导入导出优化:
  - 支持自定义列宽
  - 提供多种数据转换器
  - 优化大数据量处理
